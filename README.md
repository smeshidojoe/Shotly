# Shotly

Скриншоты как в Lightshot — выделить область, порисовать поверх, скопировать или
сохранить. Без выгрузки на сервер: всё остаётся на вашем компьютере.

</div>

## Что умеет

- **Выделение области** поверх затемнённого экрана, сразу на всех мониторах.
  Рамку можно двигать и тянуть за восемь ручек, размер видно в подписи.
- **Снимок окна целиком**: наведите курсор — окно под ним подсветится, двойной
  клик выделит его границы. Окно перерисовывается заново, поэтому в кадр не
  попадает то, что лежало поверх него. Дальше как обычно: порисовать,
  скопировать, сохранить.
- **Рисование поверх снимка**: карандаш, линия, стрелка, фигура (прямоугольник,
  скруглённый прямоугольник или овал), маркер, ластик, заливка, перо и текст — любым цветом из палитры
  (или своим из системного выбора цвета) и любой из четырёх толщин. Рисовать
  можно по всему экрану, не только внутри рамки; в файл и буфер уходит
  выделенная область, остальное обрезается.
- **Вставка картинки** поверх снимка: логотип, стрелку-указатель или любую
  другую заготовку можно подвинуть и растянуть прямо в кадре.
- **Размытие** двух видов — пиксельное и мягкое, четыре градации силы.
  Замазать можно рамкой, как выделяют область, или кистью от руки.
- **Копирование в буфер** и **сохранение в файл** (PNG / JPG / BMP) — по кнопке,
  горячей клавише или двойным кликом по выделению.
- **Печать** снимка через системный диалог.
- **Снимок всего экрана** отдельной горячей клавишей: сразу в файл или в буфер.
- **Имена по порядку**: `Screenshot_1`, `Screenshot_2`, … Программа занимает
  первый свободный номер в папке, поэтому удалённые снимки не оставляют дыр в
  нумерации. Шаблон настраивается.
- **Автозапуск** с Windows и **обновление из настроек** по релизам GitHub.

Программа работает из трея: левый клик по иконке — снимок, правый — меню. Съёмка
начинается только по горячей клавише или из трея: запуск программы, в том числе
при старте Windows, сам по себе оверлей не открывает. Повторный запуск ярлыка
при уже работающей программе просто ничего не делает.

## Горячие клавиши

| Где | Сочетание | Что делает |
|-----|-----------|------------|
| Глобально | `Prnt Scrn` | выделить область |
| Глобально | `Shift + Prnt Scrn` | весь экран в файл (выключено по умолчанию) |
| Глобально | `Ctrl + Prnt Scrn` | весь экран в буфер (выключено по умолчанию) |
| В оверлее | `Ctrl + C` / двойной клик по рамке | скопировать выделенное |
| В оверлее | двойной клик по подсвеченному окну | выделить окно целиком |
| В оверлее | `Ctrl + S` | сохранить выделенное |
| В оверлее | `Ctrl + P` | напечатать |
| В оверлее | `Ctrl + Z` | отменить последнюю фигуру |
| В оверлее | `Ctrl + A` | выделить весь экран |
| В оверлее | `Shift` при рисовании | ровная линия, квадрат, круг |
| В оверлее | `Alt` при рисовании | фигура растёт из точки нажатия |
| В оверлее | `Shift + Alt` | ровный квадрат или круг из центра |
| В оверлее | `Delete` | убрать вставленную картинку |
| В оверлее | `Esc` | шаг назад: текст → палитра → инструмент → выход |
| В оверлее | `V` | инструмент выбора |
| В оверлее | двойной клик по элементу | правка его узлов |
| В оверлее | `Alt` при работе пером | двигать узлы и ручки |
| В оверлее | правая кнопка на кнопке инструмента | показать формы |
| В оверлее | `Delete` / `Backspace` | убрать выбранный элемент |
| В оверлее | `Alt` + правая кнопка, вести вбок | толщина инструмента |
| В оверлее | колесо мыши | форма фигуры, заливки или размытия |
| В оверлее | правая кнопка на пустом экране | закрыть съёмку |

Пока выбран инструмент, клик за рамкой рисует, а не начинает новое выделение.
Чтобы выделить другую область, отключите инструмент — повторным кликом по его
кнопке или `Esc`.

Все три глобальных сочетания меняются в настройках.

## Настройки

Открываются из меню трея, четыре вкладки:

- **Основные** — автозапуск, уведомления, память о рамке выделения, курсор в
  кадре, подсветка окон, перекрестие вместо курсора, папка сохранения, язык
  (меняется сразу), сброс настроек.
- **Горячие клавиши** — три назначаемых сочетания.
- **Форматы** — PNG / JPG / BMP, качество JPEG, шаблон имени файла, спрашивать
  ли путь при каждом сохранении.
- **Обновления** — уведомления о новых версиях, проверка и установка.

## Курсор и подсветка окон

По умолчанию в режиме съёмки курсор системный: обычная стрелка в покое и
диагональная стрелка растягивания, пока тянете рамку — та же, что Windows
показывает при изменении размера окна за угол. Кому привычнее прицел, включите
«Перекрестие вместо курсора мыши» в настройках.

Пока область не выбрана, окно под курсором подсвечивается: оно остаётся ярким,
остальной экран притушен, сверху видно его размер. Двойной клик выделяет это
окно целиком. Список окон снимается один раз, перед показом оверлея, — потом
верхним окном становится сам оверлей. Свои окна, свёрнутые, скрытые UWP и фон
рабочего стола в список не попадают, а границы берутся у диспетчера окон, а не
из `GetWindowRect`: иначе в рамку попадали бы невидимые поля Aero по 7 px.
Подсветку можно выключить в настройках.

Двойной клик не просто вырезает кусок общего снимка: окно просят нарисовать себя
заново (`PrintWindow` с `PW_RENDERFULLCONTENT`), и всё, что его перекрывало,
из кадра исчезает. Если окно нарисовать себя не даёт — запущено с правами
администратора, отдаёт кадр напрямую видеокартой — программа молча берёт обычную
вырезку, и перекрытие в снимке останется.

## Выбор, ластик, заливка и перо

**Выбор** (`V`) берёт уже нарисованное: клик по элементу обводит его рамкой с
ручками, дальше его можно двигать, растягивать (`Shift` — равномерно) и удалять
клавишей `Delete`. Работает с чем угодно — от стрелки и текста до вставленной
картинки и заливки.

Двойной клик по выбранному элементу включает правку узлов: вместо рамки
появляются сами точки, и каждую можно подвинуть отдельно. У пути, нарисованного
пером, вместе с узлами показываются их ручки — изгиб правится тут же. `Esc`
возвращает обычный режим.

**Ластик** стирает нарисованное — и штрихи, и размытие, — не трогая сам кадр.
Аннотации живут отдельным прозрачным слоем поверх снимка, поэтому стереть можно
половину фигуры, а не только фигуру целиком.

**Заливка** («ведро») закрашивает область под курсором. Границами считается
только нарисованное — фигура, кривая карандаша, путь пера; сам скриншот под ними
ведро не видит, поэтому оно не цепляется за контрасты интерфейса. Если контур не
замкнут и краска утекла бы на всё выделение, заливка не применяется, а в углу
появляется уведомление. В селекторе ведра есть второй режим — **снять заливку**:
он убирает конкретное пятно, не трогая остальную историю.

**Перо** работает как в Figma: клик ставит узел с прямым отрезком, клик с
протяжкой растягивает симметричную пару ручек и превращает отрезок в кривую, а
протяжка с `Alt` ломает симметрию — так делают углы, где кривая входит и выходит
по-разному. Наведение на первый узел подсвечивает его, клик замыкает контур,
`Backspace` убирает последний узел, `Enter` или `Esc` заканчивают незамкнутый.

Пока путь ещё строится, `Alt` переключает перо в правку: с зажатым `Alt` узлы и
ручки можно таскать мышью, не добавляя новых точек.

## Толщина на лету

Размер инструмента меняется без панелей: зажмите `Alt` и правую кнопку мыши,
ведите вправо — толще, влево — тоньше. Курсор возвращается в точку нажатия после
каждого шага, а кружок-подсказка на это время замирает там же — иначе и то, и
другое дёргалось бы по экрану. У ластика и кисти размытия своя толщина,
у остальных общая.

У карандаша, маркера, ластика и кисти размытия под курсором виден кружок ровно
того размера, каким ляжет мазок.

## Выбор формы

У кнопок «фигура», «размытие областью» и «заливка» в углу виден маленький
уголок — значит, у инструмента есть варианты. Левая кнопка просто включает
инструмент, а формы показывает **правая**: сбоку выдвигается ряд из
прямоугольника, скруглённого прямоугольника и овала. Выбранная форма остаётся на
самой кнопке, так что видно, что нарисуется.

Колесо мыши над кнопкой перебирает её варианты, даже если инструмент сейчас не
выбран; над самим кадром — варианты активного инструмента.

Раньше формы жили рядом с палитрой цветов — связь между рядом иконок и кнопкой
инструмента оттуда не читалась.

## Вставка картинки

Кнопка в предпоследней группе панели — за отдельной чертой, потому что это не
инструмент рисования, а разовое действие. Проводник открывается поверх оверлея,
так что выделение и рисунки остаются на виду. Она открывает выбор файла (PNG, JPG, BMP, GIF,
WEBP) и кладёт картинку по центру выделения, вписав в него.

Пока вокруг картинки видна рамка с ручками, её можно двигать за середину и
растягивать за края. Модификаторы те же, что у фигур: без них тянется свободно —
и за угол, и за сторону, `Shift` меняет размер равномерно, `Alt` растит от
центра. Перенос и растягивание отменяются через `Ctrl+Z`.

Клик мимо, `Esc` или выбор инструмента фиксируют картинку — дальше она обычная
фигура. `Delete` удаляет её, пока рамка ещё видна.

Слишком большие файлы ужимаются при загрузке до 4000 px по длинной стороне:
вставляют обычно логотип или вырезку, а фотография с телефона раздула бы память
на пустом месте. Поворот из EXIF учитывается.

## Размытие

Два инструмента в панели: **область** — обводите участок, и всё внутри
замазывается, и **кисть** — водите мышью, размывается след. Оба умеют одно и то
же:

| Вид | Что делает |
|-----|------------|
| Пиксели | крупные квадраты, текст под ними не собрать обратно |
| Размытие | мягкое, деталей не разобрать, картинка остаётся гладкой |

Область бывает трёх форм: прямоугольник, прямоугольник со скруглёнными углами
и овал. Форму выбирают у самой кнопки — см. «Выбор формы» ниже. Она применяется
к следующей области: уже нарисованную не перекроить.

Модификаторы работают и здесь, и у контурной фигуры: `Shift` держит
равные стороны, `Alt` растит фигуру из точки нажатия во все стороны сразу, а
вместе они дают ровный квадрат или круг с центром там, где нажали. Нажать `Alt`
можно и посреди протяжки — фигура перестроится вокруг исходной точки.

В панели инструментов размытие вынесено в свою группу, отделённую чертой: два
инструмента и третья кнопка — настройки. Она открывает панельку с видом, силой
(четыре градации) и размером кисти, а на самой кнопке видно выбранный вид:
мозаика или капля. У рисования своя настройка — палитра цветов, она осталась в
верхней группе.

Смена вида или силы применяется к последнему размытию сразу, так что подобрать
нужную степень можно, не отменяя мазок. `Ctrl+Z` убирает размытие, как и любую
другую фигуру.

## Имена файлов

Шаблон задаётся на вкладке «Форматы», под полем сразу видно пример. По умолчанию
`Screenshot_%n`.

| Код | Что подставляется |
|-----|-------------------|
| `%n` | наименьший свободный номер в папке: 1, 2, 3, … |
| `%03n` | он же с ведущими нулями: `001`, `002` |
| `%Y` `%m` `%d` | год, месяц, день |
| `%H` `%M` `%S` | часы, минуты, секунды |

Номер ищется **с единицы**, а не «последний плюс один»: если в папке есть
`Screenshot_133` и `Screenshot_135`, следующий снимок станет `Screenshot_134` и
дыра закроется. Занятым номер считается в любом из наших форматов — при
`Screenshot_7.jpg` номер 7 не достанется и файлу `.png`.

Примеры: `Screenshot_%n` → `Screenshot_140`, `%Y-%m-%d_%n` → `2026-09-02_3`,
`Shotly_%Y-%m-%d_%H-%M-%S` → `Shotly_2026-09-02_15-33-12` (без номера, как было
раньше).

## Стереть всё

Ни клик мимо рамки, ни правая кнопка мыши выделение не сбрасывают: одним
промахом иначе терялась бы вся работа. Чтобы выделить другую область, есть красная кнопка в
самом низу панели. Она с подтверждением — первый клик взводит её и показывает
галочку, второй стирает, а взвод сам спадает через три секунды. Стирание
отменяется как обычное действие.

Кнопки «Отменить», «Повторить» и «Стереть всё» выключены, пока отменять,
повторять и стирать нечего.

## Где что лежит

| Путь | Что |
|------|-----|
| `%APPDATA%\Shotly\config.json` | настройки (создаётся при первом запуске) |
| `%APPDATA%\Shotly\crash.log` | необработанные исключения |
| `%APPDATA%\Shotly\check-*.png` | мелкий служебный кэш оформления |
| `<папка установки>\_update\` | только во время обновления |
| `~\Pictures\Shotly\` | снимки по умолчанию |

Больше программа никуда не пишет и ничего не докачивает: всё, что нужно для
работы, лежит внутри exe.

# Для разработчиков

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

Windows, Python 3.13. Ctrl+C в консоли закрывает программу.

## Сборка

```bash
pyinstaller --clean --noconfirm Shotly.spec
```

Готовый `dist\Shotly.exe`. Установщик собирается Inno Setup 6 из
`shotly_setup.iss` — он читает версию прямо из exe, поэтому сначала соберите exe.

Версия живёт в одном месте: `APP_VERSION` в
[shotly/core/constants.py](shotly/core/constants.py). Оттуда её берут ресурс
версии в exe, установщик и проверка обновлений.

## Картинки проекта

```bash
python tools/make_assets.py
```

| Файл | Что это |
|------|---------|
| `assets/app.ico` | иконка exe, трея и установщика (7 размеров) |
| `assets/icon.png` | она же 1024x1024 — аватарка, страница релиза |
| `assets/app.png` | 256x256 для README |
| `assets/cover.png` | обложка 1280x720 для карточки программы |

## Структура

```
main.py                 точка входа: один экземпляр, Ctrl+C, применение обновления
```

## Автозапуск

Ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, без прав
администратора. Источник истины — галочка в настройках: на каждом старте реестр
приводится к ней. Выключено — запись удаляется, включено — перезаписывается
актуальным путём к exe (после переустановки в другую папку старый путь указывал
бы в пустоту).

На первом запуске всё наоборот: конфига ещё нет, и программа берёт состояние из
реестра — иначе галочка «Запускать при старте», поставленная в мастере
установки, тут же стёрлась бы. При удалении программы запись снимается, даже
если её создала не установка, а сама программа.

В режиме разработки реестр не трогается вообще: иначе в автозапуск попал бы
`python.exe`.

## Горячие клавиши без хуков

Сочетания регистрируются системным `RegisterHotKey`: Windows сама следит за
клавишей и присылает сообщение. Хук клавиатуры не ставится, чужие нажатия через
программу не проходят и ничем не подавляются.

Раньше использовался низкоуровневый хук с подавлением — он пропускал через себя
каждое нажатие в системе и мог оставить модификатор «залипшим». Осталась только
подстраховка: если сочетание уже занято другой программой (RegisterHotKey
эксклюзивен), подключается библиотека `keyboard`, но уже без подавления.

## Как устроено обновление

Проверка идёт в фоне: первая через 8 секунд после старта, дальше раз в два часа.
Если релиз новее текущей версии и в нём есть zip с `Shotly.exe`, появляется
уведомление; клик по нему открывает настройки и сразу качает, крестик — «больше
не напоминать про эту версию».

На время загрузки окно настроек запирается: поверх него ложится затемнение с
полосой прогресса, крестик прячется, `Esc` и закрытие не работают. Закрытое
посреди скачивания окно оборвало бы обновление.
